# HyperFrames production project

This directory is the deterministic HyperFrames edition of EMPAT ORANG Episode 01.

- [SPEC.md](SPEC.md): locked visual/audio/delivery brief and 22-shot plan.
- [STORYBOARD.md](STORYBOARD.md): continuity and render rules.
- `index.html`: composition root (next migration step).
- `compositions/`: one editable scene per shot/sequence.
- `assets/`: local audio, image and font assets.

The legacy Three.js player at the repository root remains available while the HyperFrames version is built and validated. Do not replace it until the HyperFrames preview and MP4 pass review.
