# Character GLB assets

Place the final rigged character models here:
- zio.glb
- erla.glb
- olaf.glb
- den.glb

Requirements:
- Consistent stylized 3D art direction and scale.
- Humanoid skeleton with a consistent rest pose.
- Named animation clips where possible (for example: Idle, Walk, Run, LookBack, Scared).
- Facial morph targets or a facial rig are strongly recommended.
- Keep each character's identity, hair, clothing, and proportions consistent across episodes.

Do not upload placeholder or unrigged models as final assets.
