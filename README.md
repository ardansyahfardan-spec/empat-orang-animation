# EMPAT ORANG — Episode 01: Rumah yang Memanggil

Proyek animasi 2D vertikal untuk serial EMPAT ORANG.

- Kanvas pratinjau: 540×960 (9:16), dapat dibuka di iPhone Safari.
- Target ekspor: 1080×1920, 30 FPS, MP4 H.264.
- Durasi target: 92 detik.

## Status
Ini prototipe visual awal: susunan adegan, gerak sederhana, dan teks cerita sudah ada. Desain karakter yang akurat, akting, narasi suara laki-laki, musik, dan efek suara belum selesai. Jangan anggap ini sebagai episode final.

## Render
Jalankan workflow "Render episode MP4" dari tab Actions. MP4 hanya dianggap selesai setelah workflow berhasil dan hasilnya diperiksa.
