# EMPAT ORANG — Episode 05
## Ruangan di Balik Lemari

Episode ini diproduksi secara mandiri. Episode 01 bukan prasyarat dan tidak menjadi sumber cerita.

### Sumber produksi
- Storyboard berurutan: `produksi/storyboard/IMG_2889.jpeg` sampai `IMG_2897.jpeg`.
- Audio utama: `produksi/voice-over/Eps 05.mp3`.
- Naskah: enam adegan sesuai naskah Episode 05 yang diberikan pengguna.

### Output
- Portrait 9:16, 1080×1920
- 30 fps
- MP4 H.264 + AAC
- Durasi mengikuti audio sumber (target 90–120 detik)

### Render
Perubahan pada folder `episode-05/`, storyboard, audio, atau workflow ini memicu GitHub Actions. Hasil MP4 akan tersedia sebagai artifact pada workflow run.

### Catatan visual
Render awal adalah *motion-comic animatic*: sembilan gambar storyboard dipertahankan sesuai urutan dengan gerakan kamera digital, reframing, transisi sinematik, dan ambience rendah. Ini bukan klaim bahwa rig karakter 3D atau gerakan anggota tubuh sudah dibuat. Tahap rigging/character animation memerlukan pemisahan layer atau model karakter yang dapat dianimasikan.

### Audio
File MP3 yang sudah diunggah dipakai sebagai audio utama. Workflow menambahkan ambience sintetis halus dengan level rendah; dialog tidak diganti atau dibuat ulang.
