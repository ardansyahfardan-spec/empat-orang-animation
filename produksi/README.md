# PRODUKSI ANIMASI EMPAT ORANG

Folder kerja produksi untuk episode animasi vertikal EMPAT ORANG.

## Struktur
- `storyboard/` — storyboard, shot list, dan arahan adegan.
- `voice-over/` — file narasi/dialog sumber. Jangan unggah file pribadi sebelum memastikan akses repository.
- `assets/` — ilustrasi, desain latar, properti, dan referensi visual.
- `scenes/` — data dan implementasi tiap adegan animasi.
- `audio/` — musik latar, ambience, dan sound effect.
- `exports/` — hasil render MP4 dan preview.

## Target output
- Portrait 9:16
- 1080 × 1920
- 30 FPS
- MP4 H.264

## Alur kerja
1. Masukkan storyboard dan voice-over episode.
2. Pecah voice-over menjadi shot/adegan dengan timecode.
3. Siapkan visual dan gerakan kamera per adegan.
4. Sinkronkan dialog, ambience, musik, dan subtitle.
5. Preview, render, lalu periksa MP4 final.

Catatan: repository ini saat ini bersifat public. Jangan menyimpan audio atau materi yang belum boleh dipublikasikan di sini. File placeholder hanya menyiapkan struktur; belum berisi aset episode.
